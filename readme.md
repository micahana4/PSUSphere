# PSUSphere

PSUSphere is a **Django-based** student organization management system for Palawan State University. It helps manage colleges, programs, organizations, students, and organization memberships in one system.

## Features

- Manage college information
- Manage academic programs
- Manage student organizations
- Manage student records
- Manage organization members
- Manage student organization memberships
- View and manage records through Django Admin
- Search and filter records in the Django Admin
- Generate initial sample data using Faker
